examdata 统一网关 · 浏览器端最小示例

用浏览器原生 fetch 调 GET /api/v1/search（跨考试局检索，读服务端数据库）。 页面不依赖任何框架，双击打开即可；把 服务地址 换成你的服务地址再点“检索”。

为什么需要服务端开 CORS： 本页面与 API 不同源，浏览器会先发预检请求；服务端没开 CORS 时，请求会被同源策略拦下， 控制台报 blocked by CORS policy。给服务进程加一个环境变量再启动即可： 
EXAMDATA_CORS_ORIGINS='*' examdata serve --port 8000
# 或只放行本页所在来源（更安全）
EXAMDATA_CORS_ORIGINS='http://127.0.0.1:5500' examdata serve --port 8000
CORS 由服务端 EXAMDATA_CORS_ORIGINS 控制，不配置就不挂中间件——本地同源调用不受影响。

双击打开（file://）时只能用 '*'： 这时页面的 Origin 是 null，实测白名单模式不会回 access-control-allow-origin（预检直接 400），浏览器就会拦下请求。 想用白名单，就把本文件放到本地 HTTP 服务下再访问：在仓库根执行 python -m http.server 5500 --directory examples，然后打开 http://127.0.0.1:5500/browser.html，此时白名单写 http://127.0.0.1:5500 即可。

不要把 API Key 写进公开页面： 这里的输入框只适合本机调试。公开页面里的 Key 等同于公开，浏览器端调用应当放在你自己的后端转发。
