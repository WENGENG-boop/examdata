# B07 operations-root fixture tree (synthetic, private rehearsal)

A read-only scan root shaped like a real operations directory: one
`<scope>/checkpoint.json` per scope (or two, for the supersession pairs).
Every identifier, timestamp and message is invented for the B07 private
rehearsal; there is no real batch state, run state, credential or upstream
content anywhere in this tree, and the staged API only ever reads it.

| Path | Native shape | Drives |
| --- | --- | --- |
| `cie-location-batch/checkpoint.json` | CIE batch `checkpoint.json`, stopped with a pending user resume (newest snapshot of its scope) | `stopped_requires_resume`, resume preserved; its stop detail deliberately carries a fake filesystem path and a fake secret so public redaction can be tested |
| `cie-batch-8888/checkpoint.json` | CIE batch `checkpoint.json` still running (newer snapshot) | `running`, missing stop fields stay `None` |
| `cie-batch-8888-stale/checkpoint.json` | CIE batch `checkpoint.json`, earlier stop for the same subject | superseded row keeps the native `stopped` word and never overrides the newer file |
| `run-ok/checkpoint.json` | `ielts-run-checkpoint/1` healthy run (newer snapshot) | `succeeded`, counters/sources verbatim |
| `run-ok-stale/checkpoint.json` | `ielts-run-checkpoint/1`, same run id, earlier `updated_at` | stale partial report stays superseded, never overriding the healthy newer node |
| `run-partial/checkpoint.json` | `ielts-run-checkpoint/1` with one blocked source | `partial`, counters never zeroed, blocked source visible |
| `unsupported/checkpoint.json` | neither native format | `unknown` row with explicit problems, never dropped |

`expected-manifest.json` declares the published-data denominators by hand: an
undeclared denominator can never render a percentage, an explicit partial
expectation or exclusion is a reasoned authored classification, and a scope
that does not meet its denominator stays `partial`.

`PROVENANCE.json` records every file with its sha256 and byte count and is
regenerated by `integration-staging/runtime/b07-rehearsal-2026-10-07/tools/
author_operations_root.py`; the B07 build re-verifies the recorded hashes
against both this source tree and the staged candidate copy.
